# 控制面 API

网页桌面与管理面走同一套 HTTP API（Fastify + 会话 cookie 认证）。以下是**分组与权限**，完整端点定义见 `src/web/routes/*.ts`。

| 分组 | 权限 |
|---|---|
| 认证 / 会话 · 每用户密钥 | 登录用户 |
| 网页桌面 / 文件 · 实例生命周期 | 登录用户（限自己；文件操作在路径围栏内） |
| 技能 · 插件 | 共享技能层与插件候选池 = 管理员；个人技能与插件启停 = 本人 |
| 用户与审核 · 官方目录白名单 · 运维只读 | 管理员 |
| 自定义域名 | 本人 / 管理员 |
